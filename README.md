# 📚 ITDD & IT Integration Flashcards

320 English vocabulary terms at **CET-6+ level** focused on **IT Due Diligence** and **IT Integration**.

## Use It

👉 **[flashcard-app](https://commaluanqibazao.github.io/flashcard-app/)**

## Features

- 320 terms across 16 categories
- Flip card UI — tap to reveal answer
- Mark Known / Unknown, track progress
- Category filter, review modes
- Progress saved in browser (localStorage)
- Fully offline — no server needed

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| Space / Enter | Flip card |
| K | Mark known |
| U | Mark unknown |
| S | Skip |
| 1 | All words |
| 2 | Unknown only |
| 3 | Known only |
